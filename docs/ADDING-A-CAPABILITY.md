# Add a capability

Skills live in `skills/` (submodules). Everything else is a **component** declared in
`plugin.config.json` and generated into the host manifests:

| Component | Files | Claude Code | Agent Plugins hosts (Codex/Cursor/…) |
| --- | --- | --- | --- |
| command | `commands/<name>.md` | `commands` field | not portable; keep Claude-only |
| agent | `agents/<name>.md` | `agents` field | not portable; keep Claude-only |
| hook | `hooks/hooks.json` | `hooks` field | `extensions.com.openai.hooks` |
| MCP server | generated `mcp.json` + `.mcp.json` | `mcpServers` | root `mcp.json` (typed servers) |

The declarative source is `components` in `plugin.config.json`; manifests are
regenerated by `npm run sync`, and `npm run check` fails when they drift.

## Command

```bash
npm run add-component -- command my-command --description "When to use /my-command"
```

Creates `commands/my-command.md`, adds it to `components.commands`, regenerates the
Claude manifest (`commands: ["./commands/my-command.md"]`). Invoke it as
`/ascend-dev-skills:my-command`.

## Agent

```bash
npm run add-component -- agent reviewer --description "Review changed files"
```

Creates `agents/reviewer.md` and adds it to `components.agents`. Claude Code namespaces
it as `ascend-dev-skills:reviewer`.

## Hook

```bash
npm run add-component -- hook
```

Creates `hooks/hooks.json` (`{"hooks": {}}`), sets `components.hooks`, and regenerates
both the Claude `hooks` field and `extensions.com.openai.hooks`. Add real events per the
Claude Code and Codex hooks references; an empty hook file produces a validation warning.

## MCP server

```bash
npm run add-component -- mcp-server docs --transport streamable-http
```

Adds an entry to `components.mcpServers` with `command: "TODO"`. Fill in `command`/`url`
and the rest of the server config, then:

```bash
npm run sync && npm run verify
```

The generator writes:

- `mcp.json` — Agent Plugins format (`{"mcpServers": {"docs": {"type": "streamable-http", ...}}}`);
- `.mcp.json` — Claude Code format (no `type`).

`verify` refuses a server that still contains `TODO`, so an unfinished scaffold cannot
ship by accident. MCP servers are optional; a plugin with only skills leaves both files
absent.

## Per-host notes

- **Claude Code** accepts `commands` (path/array/map), `agents` (array of `.md` files),
  `hooks` (path/object), and `mcpServers` (path/object). `skills/` is scanned by default,
  so the manifest does not list it.
- **Agent Plugins** only standardizes `skills/` and `mcp.json`; keep other components out
  of the portable manifest and use the Claude manifest (or an `extensions` namespace) for
  host-specific behavior.
- **Cursor** reads `plugin.json`; Cursor-specific rules/hooks belong in a separate
  `.cursor-plugin/` package if you ever need them.

## Verify

```bash
npm run sync
npm run check
npm run verify
claude plugin validate .
claude plugin validate .claude-plugin/marketplace.json
```

Validation must pass before committing component changes.
